声音设计

每种通知事件都有独立的声音语义，而不是通过重复播放提示音的次数来区分事件。

  • done — 正常完成
  • permission — 需要审批（等待人工操作）
  • question — Agent 正在等待你的回答
  • block — 目标受阻，无法继续
  • error — 发生了错误

声音素材来自 react-sounds。 仅使用上述五种声音；本页为独立展示页，与 react-sounds 无关联。

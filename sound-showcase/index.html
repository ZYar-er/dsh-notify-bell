Sound design

Each event has its own semantic sound identity. The notification system does not rely on counting repeated beeps to communicate meaning.

  • done — normal completion
  • permission — approval required (human action pending)
  • question — the agent is waiting for your answer
  • block — goal blocked
  • error — something went wrong

Sound assets are sourced from react-sounds. Only the five referenced sound names are used; this page is an independent showcase and is not affiliated with react-sounds.
